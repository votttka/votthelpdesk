# HelpDesk Prototype

Интерактивный кликабельный макет helpdesk-системы для демонстрации интерфейса и логики работы.

## Демо

**[Открыть прототип](https://votttka.github.io/votthelpdesk/)**

## Возможности прототипа

### ✅ Реализованный функционал

1. **Статусная модель с цветами и SLA**
   - 7 статусов: Новая, Классификация, В работе, Ждём ответа, Пауза, Закрыта, Архив
   - Цветовая индикация статусов
   - Таймер SLA с визуальной индикацией просрочки
   - Остановка таймера при статусах "Ждём ответа" и "Пауза"

2. **Переходы между статусами**
   - Правила переходов в зависимости от роли
   - Обязательная причина для "Ждём ответа" и "Пауза"
   - Обязательный канал решения при закрытии

3. **Роли и права доступа**
   - 6 ролей: Оператор, Инженер, Супервизор, Лид, Администратор, Аудитор
   - Переключение ролей в интерфейсе
   - Разные права для каждой роли

4. **Дашборд**
   - Счётчики заявок по статусам
   - Список просроченных заявок
   - Заявки с истекающим SLA
   - Таблица всех заявок

5. **Список заявок**
   - Поиск по номеру, теме, контрагенту
   - Фильтры по статусу, типу, признаку клиентская/внутренняя
   - Сортировка по колонкам

6. **Карточка заявки**
   - Все поля заявки
   - Кнопки смены статуса (зависят от роли)
   - Вкладка "Взаимодействия" с комментариями
   - Вкладка "Аудит-лог" с полной историей
   - Таймер SLA

7. **Создание заявки**
   - Обязательная типизация
   - Признак клиентская/внутренняя
   - Комментарий для типа "Другое"

8. **Страница настроек**
   - Статусы и переходы
   - Автоматика
   - Воронки
   - SLA нормативы
   - Роли и права

9. **Фиктивные данные**
   - 28 тестовых заявок во всех статусах
   - Просроченные заявки для демонстрации
   - Заявки на паузе и ожидании

## Технологии

- React 18 + TypeScript
- Ant Design UI
- React Router
- Day.js для работы с датой
- localStorage для хранения данных
- Vite для сборки
- GitHub Pages для деплоя

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Данные

Все данные хранятся в localStorage браузера:
- `helpdesk_tickets` — заявки
- `helpdesk_currentRole` — текущая роль

Для сброса данных используйте кнопку в настройках или очистите localStorage.

## Ограничения прототипа

- Нет реальной авторизации (только эмуляция ролей)
- Нет реального бэкенда (все данные в localStorage)
- Нет интеграций с внешними системами
- Нет реальных уведомлений
- Таймеры SLA не обновляются в реальном времени (только при загрузке)
