# HelpDesk Prototype

Прототип единой системы учёта обращений для поддержки, инженеров, методологов, руководителей и клиентов.

## 🎯 Цель продукта

Создать работающий веб-прототип helpdesk, демонстрирующий:
- Единое окно для инцидентов, запросов на обслуживание, платных работ и внутренних задач
- Обязательную типизацию обращений
- Статусную модель с паузой
- Аудит-лог
- Базовый поиск
- Роли
- Простые отчёты
- Заглушки интеграций

## ⚠️ Ограничения инфраструктуры

**Запрещено:**
- Локальные компьютеры, ноутбуки, рабочие станции
- Mac, Windows-машины или личные/корпоративные ПК
- Физические серверы
- Ручные установки на чужом оборудовании
- Локальные базы данных, требующие администрирования

**Разрешено:**
- Git-репозиторий как единственный источник кода
- Issues / Projects / Boards для планирования
- CI/CD на базе бесплатных облачных runner'ов (Linux)
- Статический хостинг (GitHub Pages, Netlify, Vercel, Cloudflare Pages)
- Браузер как основная среда проверки
- Бесплатные управляемые сервисы без оплаты
- Локальное хранение данных через localStorage / IndexedDB / JSON-файлы

## 🚀 Быстрый старт

### Просмотр прототипа в браузере

1. Откройте `src/index.html` в любом современном браузере
2. Или используйте GitHub Pages / Netlify для деплоя

### Разработка

```bash
# Установка зависимостей (если используются)
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка для продакшена
npm run build

# Запуск тестов
npm test
```
