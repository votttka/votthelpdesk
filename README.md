# HelpDesk Prototype

Интерактивный кликабельный макет helpdesk-системы для демонстрации интерфейса и логики работы.

## 🌐 Демо

[https://votttka.github.io/votthelpdesk/](https://votttka.github.io/votthelpdesk/)

## 🚀 Запуск локально

```bash
npm install
npm run dev
```

## 📦 Сборка

```bash
npm run build
```

## ✨ Возможности прототипа

### Статусная модель с цветами и SLA
- 7 статусов: Новая, Классификация, В работе, Ждём ответа, Пауза, Закрыта, Архив
- Цветовая индикация статусов
- Таймер SLA с остановкой при паузе
- Визуальное отображение просрочки SLA (красный цвет)

### Переходы между статусами
- Правила переходов с проверкой прав
- Обязательные поля при смене статуса:
  - Причина для "Ждём ответа" и "Пауза"
  - Канал решения для "Закрыта"
  - Комментарий к переходу

### Минимальная автоматика
- Автопереход из "Ждём ответа" в "В работе" через 24 часа
- Автопереход из "Закрыта" в "Архив" через 30 дней
- Уведомление за 30 минут до просрочки SLA
- Автоматическое логирование всех событий

### Роли и права доступа
- **Оператор**: создание заявок, перевод в классификацию
- **Инженер**: работа с заявками, смена статусов
- **Супервизор**: переназначение, передача между линиями
- **Лид**: полный доступ + настройки
- **Администратор**: полные права включая управление пользователями
- **Аудитор**: только чтение + экспорт

### Страница настроек
- Конфигурация статусов и цветов
- Настройки автоматики
- Воронка заявок
- Нормативы SLA по типам заявок
- Права доступа по ролям

### Интерфейс
- Дашборд со статистикой и просроченными заявками
- Список заявок с фильтрами и поиском
- Карточка заявки со всей информацией
- Взаимодействия (комментарии, звонки)
- Полный аудит-лог

## 🗄️ Хранение данных

Все данные хранятся в `localStorage` браузера. Для сброса демо-данных используйте кнопку на странице настроек.

## 📊 Фиктивные данные

Прототип включает 28 тестовых заявок в разных статусах:
- 5 заявок: Новая
- 3 заявки: Классификация
- 7 заявок: В работе (2 с просрочкой SLA)
- 3 заявки: Ждём ответа
- 2 заявки: Пауза
- 5 заявок: Закрыта
- 3 заявки: Архив

## 📝 Инструкции

### Смена роли
Используйте выпадающий список в правом верхнем углу для эмуляции разных ролей.

### Создание заявки
1. Нажмите "Создать" в меню или "Новая заявка" в шапке
2. Заполните обязательные поля
3. Если выбран тип "Другое", укажите комментарий

### Смена статуса
1. Откройте карточку заявки
2. Нажмите кнопку нужного статуса
3. Заполните обязательные поля в модальном окне

### Просмотр аудита
Откройте вкладку "Аудит-лог" в карточке заявки для просмотра полной истории изменений.
