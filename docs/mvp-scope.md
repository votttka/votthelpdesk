## Технические ограничения MVP

| Ограничение | Описание | Влияние |
|-------------|----------|---------|
| localStorage | Данные хранятся в браузере | Теряются при очистке кэша |
| Нет бэкенда | Всё работает в браузере | Нет синхронизации между устройствами |
| Эмуляция ролей | Без реальной авторизации | Не является системой безопасности |
| Mock интеграции | Все внешние системы — заглушки | Требуют будущей реализации |
| ~5MB лимит | Ограничение localStorage | Максимум несколько тысяч заявок |

## Демо-сценарий

1. **Открыть прототип**
   - Перейти на GitHub Pages URL
   - Или открыть `src/index.html` локально

2. **Выбрать роль**
   - Использовать переключатель ролей в хедере
   - Выбрать «Оператор»

3. **Создать заявку**
   - Нажать «Новая заявка»
   - Выбрать тип «Инцидент»
   - Выбрать «Клиентская»
   - Заполнить поля
   - Сохранить

4. **Изменить статус**
   - Открыть заявку
   - Перевести в «В работе»
   - Перевести в «Ожидание клиента»
   - Указать причину паузы

5. **Закрыть заявку**
   - Перевести в «Решена»
   - Выбрать канал решения
   - Перевести в «Закрыта»

6. **Посмотреть аудит-лог**
   - Открыть вкладку «Аудит-лог»
   - Убедиться, что все события зафиксированы

7. **Проверить дашборд**
   - Перейти на главную
   - Посмотреть статистику

8. **Проверить интеграции**
   - Открыть панель интеграций
   - Нажать кнопки эмуляции
