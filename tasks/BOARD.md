## Процесс работы

1. **Создание задачи**
   - Штаб создаёт задачу в `tasks/TASK-XXX.md`
   - Указывает цель, версию кода, среду выполнения, разрешённые данные
   - Добавляет в BACKLOG на этой доске

2. **Назначение исполнителя**
   - Штаб назначает исполнителя
   - Задача перемещается в IN PROGRESS

3. **Выполнение**
   - Исполнитель создаёт ветку `feature/TASK-XXX`
   - Реализует функционал
   - Добавляет тесты
   - Обновляет документацию

4. **Ревью**
   - Исполнитель создаёт Pull Request
   - Задача перемещается в REVIEW
   - Reviewer проверяет изменения
   - При необходимости — независимое ревью Claude

5. **Приёмка**
   - Штаб проверяет результат
   - Запускаются автоматические тесты
   - При успехе — merge в main
   - Задача перемещается в DONE

6. **Отчёт**
   - Исполнитель создаёт отчёт о завершении задачи
   - Указывает commit SHA, среду выполнения, проверки
   - Отмечает непроверенные места
